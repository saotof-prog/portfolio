## 🚀 Projets

### CyberTalent AI — Plateforme SaaS de Recrutement Cybersécurité
*Next.js 16 · TypeScript · Prisma · Clerk Auth · Gemini AI · Neon PostgreSQL · Tailwind v4*

- **CyberScore™ IA** (0-100) basé sur certifications, labs CTF, skills et GitHub
- 3 portails : Candidat (dashboard), Recruteur (recherche & matching sémantique), Admin (modération)
- Google Gemini 2.0 Flash pour analyse de profil et génération de questions techniques
- 28 tables Prisma, rate limiting, Zod validation, 60 tests unitaires
- 🔗 [Live](https://cyber-talent-ai.vercel.app) · [GitHub](https://github.com/saotof-prog/CyberTalent-AI)

### ATM — Agence Événementielle Premium
*Next.js 16 · TypeScript · Framer Motion · Tailwind CSS v4*

- Site vitrine luxueux : événementiel, hôtes, mannequins, conciergerie, location de robes
- Galerie photo immersive avec lightbox et filtres
- Design sombre `#000033` avec accents dorés, glassmorphism
- 🔗 [Live](https://atm-web-site.vercel.app) · [GitHub](https://github.com/saotof-prog/ATM-Web-Site)

### CAD Store — E-commerce de Luxe (116 produits)
*Next.js 14 · Tailwind CSS · TypeScript*

- Catalogue en 5 catégories (costumes, chemises, chaussures, accessoires)
- Panier slide-over, wishlist, recherche live, commandes WhatsApp
- Admin panel avec gestion de stock inline, badges rupture/stock limité
- API REST, newsletter, curseur custom, WCAG
- 🔗 [Live](https://cad-store.vercel.app) · [GitHub](https://github.com/saotof-prog/cad-store)

### Air Canvas Pro — Dessin dans l'Air par IA

- 5 gestes, 5 couleurs, épaisseur variable, replay, HUD temps réel
- 🔗 [Live](https://saotof-prog.github.io/Proget-air-canva-pro/) · [GitHub](https://github.com/saotof-prog/Proget-air-canva-pro)
